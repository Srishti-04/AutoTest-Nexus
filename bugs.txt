Bug ID: BUG-001
Title: Flash message contains unwanted text

Description:
After login, the success message contains extra characters like '×' which affects readability.

Steps to Reproduce:
1. Open login page
2. Enter valid credentials
3. Click on login button

Expected Result:
Clean success message should be displayed.

Actual Result:
Message contains extra symbols and formatting issues.

Severity: Low
Priority: Medium
Status: Open
